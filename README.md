# 🚍 Transportation Delay Prediction (AI Project)

## 📌 Project Overview
This project focuses on predicting **bus delay time (in minutes)** using a real-world transportation dataset containing noisy, missing, and inconsistent data.

The goal was to clean the dataset, engineer meaningful features, explore patterns, and build accurate machine learning models.

---

## 📊 Dataset Description
The dataset includes:
- Scheduled and actual times
- Passenger count
- GPS coordinates (latitude & longitude)
- Weather conditions
- Route identifiers

The dataset required extensive cleaning and preprocessing before modeling.

---

## ⚙️ Key Steps
- Data Cleaning & Formatting
- Handling Missing Values & Outliers
- Feature Engineering:
  - Time of day
  - Day type (weekday/weekend)
  - Weather severity
  - Route frequency & historical delay
- Exploratory Data Analysis (EDA)

---

## 🤖 Machine Learning Models
The following models were implemented and evaluated:
- Linear Regression
- Decision Tree
- **Random Forest**
- **Gradient Boosting**

📈 **Best Performing Models:**
- Random Forest
- Gradient Boosting

---
